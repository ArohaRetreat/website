# Guest experience 0.14.0

Owner: the existing Aroha website service. Guest identity, optional Analytics and location presentation are frontend modules, not separate deployed services.

`firebase-auth.mjs` owns the shared session-scoped Google Auth instance. `firebase.mjs` remains the admin API/Storage adapter. `guest-account.mjs` lazy-loads Auth when an account is opened or a same-tab guest-session marker exists; the marker stores no name/email/token. Auth is ready before the enabled Continue with Google button calls its popup directly in a user gesture. Only a signed-in visitor's own escaped profile appears in the native dialog. Sign-out, popup cancellation/blocking, network failure and preview-domain errors are explicit. No host role is inferred from Google identity, and no booking/availability/room hold/payment is implied.

`analytics.mjs` lazy-loads `firebase-analytics.mjs` only when the new aroha-analytics preference is explicitly allowed. Collection is limited to the canonical aroharetreat.com host, excluding private draft previews, admin/design routes, localhost, preview-channel and emulator traffic. Existing aroha-monitoring consent covers Dynatrace alone and does not silently opt a visitor into Google Analytics. Firebase uses the existing public G-D4WTRKW4N9 measurement ID. The consent is checked again after asynchronous loading/support checks; withdrawal disables collection and clears site GA cookies. Page/referrer URLs omit query/hash fields, advertising signals are disabled, and private WhatsApp enquiry URLs are opened directly from the submit gesture rather than placed in observable DOM links. Names, emails, phone numbers and enquiry text are never assigned as analytics user identity/properties/events. Emulators do not initialize live Analytics. Dynatrace remains independently consent-controlled.

`location-map.mjs` renders the supplied address and Google Maps share embed for Aroha Retreats(Hrudhi Farms), coordinates 12.5338071,77.4562976. The iframe has no initial src; Show Google map explicitly loads it. Google’s listing has its own postal/phone presentation; website contact details continue to use the host-supplied brief. Do not silently copy listing phone numbers into host content.

`hrudhi-guide.mjs` uses the original neutral character portrait at rest and a reference-derived, eight-frame, 4-by-2 painted walk sheet during a short change of selected place. The tour companion is beneath destination steps. The map companion is a narrative guide, separate from the existing physical location marker; its animation is not a claimed surveyed walking path. Source master remains under Natura/review/hrudhi-performance/walk-guide-v1; the transparent WebP is a website derivative. Pause/dispose finite movement on dialogs/hidden/offscreen state; reduced motion positions her immediately. Her clickable introduction stays clearly fictional and separate from real hosts.

Gate v2 exports use the original 1344x756/24fps take, repeat frames into a 60fps file, Lanczos scaling and restrained sharpening, without optical-flow frame blending. This removes interpolation ghosting, raises web quality and mobile resolution, but cannot recover source detail or claim native 4K/60 motion. The approved 4K60 study master remains unchanged in Natura. Web desktop is 1920x1080 (~21 MB), phone 1280x720 (~10 MB), silent H.264, faststart, 12-frame keyframe intervals, loaded only near the entrance; Save-Data does not fetch film. Do not equate encoded FPS with sustained physical-device rendering.

Validate contract/consent race tests, independent non-member rules denial, Auth/Storage bundle separation, actual Google popup on the production authorized domain, map load, guide movement/stop, Discover this place, 320/390 widths and 200% browser zoom. Preview-domain OAuth failure is distinct from production OAuth. No successful booking or native RUM-to-backend linkage is certified by guest sign-in.
